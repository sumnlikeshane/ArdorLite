# Publication prose and technical review

Preserve the recorded research decisions, qualifiers, units, precision, dates, nulls, source identities, routes, anchors and material-specific rights. Metadata for an omitted original is not its contents or a new verification of it. Synthetic examples are not historical market evidence. Keep research meanings and the independently authored explanation distinct from validation or deployment status.

Shared validators and `pnpm build` check structural consistency and exact output. Run all affected direct-entry, source/claim round-trip, keyboard/history, no-JavaScript, reflow and print journeys after presentation changes. Complete three-engine evidence is required for release. Technical checks and screenshots cannot establish independent scientific review, comprehension, assistive/device acceptance or full performance; preserve actual pending/stale states and existing scope gates.

The optional prose checker extracts selected authored strings to ignored `generated/prose/`, with source/extraction hashes and segment provenance. It excludes the frozen snapshot, original captures, code and generated/vendor text. Run:

```sh
./scripts/run.sh prose:check
```

Vale is advisory and separately installed. Version **3.25.1**, upstream release/commit, the Mac ARM64 archive checksum and executable checksum are pinned in [dependencies.json](../config/vale/dependencies.json). Obtain the matching asset from that official release and verify the listed hashes before installing it at `.cache/tools/vale-3.25.1/vale`. On another platform, verify the official asset checksum for the same version and pass its explicit executable with `ARDOR_VALE_BIN=/absolute/path/to/verified/vale`. This is optional local tooling, excluded from public Git and from the required website build; no private sibling or credential is a prose dependency.

The checker creates its extraction before reporting a missing binary. A missing tool is an unavailable check, not a completed advisory review. Inspect `generated/prose/manifest.json` and `receipts/prose-advisory.json` when it completes. Findings prompt review rather than automatic rewrites of source terminology, evidence or conclusions. Preserve historical receipts separately before repeating a check.

Confidential drafts, owner tools and full factual/review/release instructions stay outside this public Git root. Included articles need deliberate promotion, complete arguments/references and material-specific rights. New research/evidence or a changed decision requires its actual separately scoped review; build success does not grant it. See [maintenance](MAINTENANCE.md), [build](BUILD.md) and [deployment](DEPLOYMENT.md).
