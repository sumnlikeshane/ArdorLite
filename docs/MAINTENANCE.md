# Maintain the single public project

Edit this checkout, run the pinned build and affected checks, and prepare an owner-controlled PR. Preserve the required `build`, `secrets`, `dependency-audit` checks, read-only tokens and pinned actions. Full browser/output binding runs within build CI. PRs receive no deployment credentials. Actual protected PR and merged-main results are required before integration/release; local tests cannot preclaim them.

Keep immutable evidence, routes, anchors, values, nulls, dates and notices unchanged. `config/publication-assets.json` remains the guarded **asset** export map. There is no recurring application source export, private canonical builder or maintained duplicate public-document template. Historical private source and records stay in independent local preservation storage.

Private originals, drafts, owner mutation CLI, full approval instructions, account details, browser recordings and operational history belong outside this Git root. Use an explicit private-root and public-repository argument for owner tools. New drafts start in private storage; `published` is inclusion metadata and is not clearance to put confidential text in Git. Promote only deliberately included, complete Markdown/JSON with material-specific rights into `src/content/entries/`. Shared `entry_check.ts` remains public and read-only. A public build rejects drafts/archives in that path.

Archive/draft withdrawal preserves original files and revisions in local history. Restore the same slug and body, then explicitly promote to restore the public source. Check inbound links and route-removal requirements; a local removal does not withdraw already hosted deep pages/assets. Never use generic entry commands to remove a canonical case or immutable evidence. Source changes invalidate relevant review/build/release bindings.

Public code is the maintained website source. Original-input integrity runs through a local audit against the exact public digest and projection. Full local authority/rights records remain authoritative; public summaries are a bounded disclosure. No original execution, captures, backtests, regenerated figures, web editing endpoint, CMS or runtime database belongs in routine maintenance.

See [build](BUILD.md), [architecture](ARCHITECTURE.md), [deployment](DEPLOYMENT.md), [contribution rules](../CONTRIBUTING.md) and [security](../SECURITY.md). Optional feedback is separate from required exact release authority. Public visibility grants no upstream write, merge or deployment access; reserved rights remain unchanged.
